# Honeybot — Scam Investigation Room

下載或複製這個儲存庫後，用瀏覽器開啟 `hackathon/demo/index.html`。展示可離線執行，無需安裝、登入或 API 金鑰。

1. 點「開始重播」。三個模擬 Agent 的 12 則訊息會依序出現，約 10 秒跑完。
2. 第 7 則訊息出現時，投資群組和兼職招募共用的 `DEMO-LOTUS-2048` 會出現在「跨會話關聯」。右側同時更新案件摘要。
3. 點「查看 S-01-3」和「查看 S-02-3」，在各自會話核對原句。切到「假客服退款」可檢視獨立的網址與驗證碼線索。
4. 點「重設」即可從頭展示。

## 匯入及匯出

下載畫面上的範例 JSON，再選擇該檔案匯入，即可驗證自訂調查流程。JSON 是會話陣列，每段提供 `title`、`agent` 和 `messages`。每則訊息包含 `role`（`peer` 或 `agent`）和 `text`。瀏覽器即時擷取對方訊息中的網址、電郵與合成收款代碼，跨會話出現完全相同的值才建立關聯。

在關聯卡核對原句後，可將覆核結果設為「待覆核」、「保留追查」或「排除」。「匯出案件報告」會下載 JSON，包含訊息和會話數量、覆核結果及原始證據。匯入在本機瀏覽器處理。點「重設」回到合成重播。

## 實作與來源

本次新增調查介面、三段合成劇本、逐訊息重播、跨會話精確值比對、原句跳轉及規則摘要。原專案的 `honeybot/clue_evaluation.py` 隨包附上，用來預先擷取網址、風險語句、付款語句及場景分類。展示新增的收款代碼規則只識別 `DEMO-*` 格式。

三個 Agent 是劇本角色，所有訊息與識別碼均為合成資料。摘要由比對結果直接組裝。相同識別碼是待查線索，仍需核對來源與持有人。

## 重建及驗證

在下載或複製這個儲存庫後的根目錄執行以下命令。重建使用 Python 3.11+，互動測試使用 Node.js，均無額外套件。

```text
python hackathon/build_replay.py
python hackathon/build_replay.py --check
node hackathon/smoke.cjs
```

互動測試使用模擬 DOM，涵蓋暫停及繼續、12 則訊息重播、關聯出現時機、兩處原句定位、獨立會話、重設。
